# PCM 单次评测报告模板

依据工程师提供的 [PCM 发版报告 V3.1.0](https://li.feishu.cn/wiki/DEMO00000000000000000000004) 整理，结构映射见 [report_template.json](../configs/report_template.json)。

## 报告结构

| 分区 | 表格 |
| --- | --- |
| 模型精度 | OCC 指标表；视觉分类汇总表；视觉子类明细表。 |
| 编译精度 | ONNX 与板端相对 GT 指标表；张量一致性表。 |

单次报告保留原模板的对应章节、指标、表头、行序、单位和格式，删除跨版本重复列，只填本次结果。模型精度与编译精度各自产生结构化结果，在报告层组合。轨迹指标扩展以工程师明确提供的模板为准。

## 填报规则

- 张量一致性与相对 GT 表现分开展示，不合成总分。
- 只填入已核验的本次模型版本、数据来源和实际执行范围，不混入其他版本或其他数据集结果。
- 小场景与全量使用相同模板和指标口径，报告展示各自真实覆盖范围。
- `无 GT 样本` 表示对应 GT 计数确认为零；`未计算` 表示未执行计算；`未提供` 表示结果缺项。真实 0 分保留 0 分，缺失值不填 0。
- 不新增自定义概览、诊断、排障过程或发版通过判断。详细来源与支持数保存在结构化结果及执行凭据中。
- 更新报告绑定目标文档与修订，发布后回读核对原始结果、JSON 和飞书表格一致，再回填卡片。

## 实现位置

- `configs/report_template.json`：原表指标及类别映射。
- `pcm_eval/reference_report.py`：组合已有模型与编译结果，生成五表结构及飞书内容。
- `pcm_eval/strict_model_template.py`：模型章节严格模板处理。
- `pcm_eval/combined_publication.py`：组合报告发布与核验。

报告生成、推理和发布保持独立，重新生成或发布报告不重复评测。模板变化需按工程师提供的原表同步映射并复核，不由程序自行增添业务指标。
